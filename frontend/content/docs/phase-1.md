# Phase 1 user guide

Aikya AI Phase 1 supports text translation and digital PDF translation.

## Translate text

Choose automatic source-language detection or select a source language, select the target language, enter up to 10,000 characters, and submit the translation.

## Translate a digital PDF

Upload a PDF that contains embedded text, choose the target language, and follow the displayed processing stages. When processing completes, use the short-lived download link.

## Current document limits

- PDF files only
- Maximum 50 MB
- Maximum 100 pages
- Scanned PDFs are not supported yet
- The readable export does not preserve the original visual layout

## Privacy note

Document content is sent to the translation provider configured by the service operator. Optional AI features are not invoked in Phase 1.
